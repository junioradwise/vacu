# VACU staging adapters

Each `extension/<track>.mjs` exports `commands`, a map of unique new CLI verbs to `async (args, ctx) => result`, where `args` is a string array without the verb. Validate arity and values; throw `Error` for invalid or unsupported requests. Existing verbs stay with the coordinator. Return JSON-serializable results; coordinate separately for screenshot artifacts. Worker tests live in `tests/<track>.test.mjs` and run with `node --test`.

`ctx` is bound to a checked selected tab by default: `tabId`, `origin`, `assertCurrent()`, `page(operation, ...args)` (existing isolated-world operations), and `waitForCursor()`. If a new injected function or CDP action is necessary, propose a named, narrow capability and its exact checks in your report; use mocks for integration seams pending coordinator review. Do not expose arbitrary JS, selectors as code, or arbitrary CDP transport. Browser-wide actions need separate routing and approval review; do not assume access from a tab-scoped handler. Report required event wiring, permissions, and constraints; leave shared integration files to the coordinator. Recheck authorization and applicable document/frame identity before side effects and before returning captured data. Unsupported operations fail closed. No credentials, private APIs, or permission expansion.
